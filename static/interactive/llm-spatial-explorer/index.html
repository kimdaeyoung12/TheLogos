Silicon and memory hierarchy

벡터는 GPU 안에서 어떤 물질로 존재할까?

숫자의 비트가 DRAM의 전하 또는 SRAM 회로의 전기적 상태로 저장됩니다. GPU는 그 숫자를 주소로 읽고, 계산에 필요한 일부를 점점 빠른 메모리로 옮깁니다.

HBM → L2 → L1/Shared → Registers

“토큰 1개 = 트랜지스터 1개”는 아닙니다.

토큰은 먼저 정수 ID입니다. 임베딩 계층이 그 ID로 가중치 행렬의 한 행을 읽어 여러 부동소수점 수로 된 벡터를 얻습니다. 하나의 BF16 숫자는 16비트이므로 4,096차원 BF16 벡터 하나에만 8,192바이트(8 KiB)가 필요합니다.

메모리 소자의 물리

DRAM / HBM: 전하를 담는 커패시터와 접근 트랜지스터(대표적인 1T1C 셀)를 이용하며 주기적 Refresh가 필요합니다.
SRAM / 레지스터·캐시 계열: 전원이 유지되는 동안 안정적인 회로 상태로 비트를 보유합니다. GPU의 모든 레지스터를 동일한 SRAM 셀로 단정할 수는 없습니다.

    숫자 계산은 어떻게 문장의 관계를 반영할까?

    단어 자체의 의미표를 찾는 것이 아니라, 학습된 행렬을 이용해 토큰의 문맥 의존 표현을 계속 갱신합니다. 아래 Attention 가중치는 계산 원리를 보이기 위한 가상 예시입니다.

    Toy Q · K · V 실험

    문장: “로봇이 컵을 탁자에서 집었다”

    토큰을 누르고 헤드를 전환하세요
    선의 두께 = 해당 가상 Attention 가중치Query · Key → Softmax

    현재 Query의 가중치

    행의 합 = 100%
    수식의 의미
    Attention(Q,K,V) =
    softmax(Q Kᵀ / √dₖ) V

    Q는 “현재 위치에서 무엇을 참조할까?”, K는 “각 위치가 가진 매칭 단서”, V는 “참조해 섞을 정보”의 수학적 표현입니다. 실제는 학습된 행렬로 만들어진 벡터이며 언어적 역할이 고정된 태그는 아닙니다.

    같은 단어도 문맥에 따라 표현이 변한다

    개념적 2D 투영 / 실제 임베딩이 아님

    “컵”을 강조하고 나머지 표현과의 상대적 배치를 움직입니다. 실제 모델의 임베딩과 중간 Hidden state는 수백~수천 차원이며 이처럼 의미별로 깨끗하게 분리된 2D 지도가 아닙니다.

    Token ID ≠ Meaning

    표현은 여러 번 재구성됩니다

    ID = 1847→초기 벡터→문맥화된 벡터→다음 토큰 점수

    첫 임베딩은 학습된 숫자 표현입니다. Attention은 현재 위치가 다른 위치 정보를 취합하는 연산이고, MLP/FFN은 각 위치 표현을 비선형 변환합니다. 이 처리들이 잔차 연결 및 정규화 등과 함께 여러 층 반복되어 다음 토큰의 분포를 계산합니다.

    Attention이 높다는 사실만으로 “모델이 그 단어 때문에 답했다”고 인과적으로 해석할 수는 없습니다. 선 그래프는 설명용이며 실제 내부 추론의 완전한 해석이 아닙니다.
    Four different meanings of routing

    무엇을 누가, 어떤 규칙으로 전송하는가?

    라우터가 IP 패킷을 전달하는 일과 GPU가 주소로 데이터를 읽는 일, MoE가 Expert를 선택하는 일은 서로 다른 계층의 문제입니다. 관점을 전환해 각각의 이동 규칙을 확인하세요.

    Logical router · top-2 example

    어떤 Expert를 실행할 것인가?

    입력 조건을 선택하면 가상 Router 점수와 선택 경로가 변경됩니다.

    실제 MoE는 모든 층에서 모든 Expert를 실행하지 않을 수 있습니다. Router는 문맥별로 Expert 점수를 계산합니다.

    Router logit → Softmax → Top-k

    r = W_router · h
    p = softmax(r)
    selected = TopK(p, k=2)
    E0~E3는 사람이 ‘로봇 전문가’, ‘언어 전문가’라고 직접 지정한 모듈이 아닙니다. 일부 전문화가 나타날 수 있지만, 실제 Expert의 역할과 선택 경로를 명료한 업무 분야로 해석하는 것은 부정확할 수 있습니다.

    S̄ = α·S전 ; 오차 = v − k·S̄ S새 = S̄ + β·k·오차 ; 출력 = q·S새

    4. 경로 재생. 기존 17단계 설명과 연결되어 각 단계의 위치로 이동합니다. KDA/MLA/MoE는 매번 한 차례만 실행되는 단계가 아니라 층마다 반복되는 구성요소입니다.
